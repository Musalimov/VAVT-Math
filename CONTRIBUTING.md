# Как вносить изменения

Спасибо, что помогаете тренажёрам! Ниже — правила, которые держат проект в рабочем состоянии.

## Ограничения, которые нельзя нарушать

1. Студент получает **один `.html` на тренажёр**, который открывается двойным щелчком (`file://`) без интернета. Внешняя зависимость — только Google Fonts с системным запасным шрифтом.
2. **Никаких фреймворков и npm-зависимостей в рантайме.** Для разработки допустим только Playwright (сверка внешнего вида).
3. **Сохранённые настройки студентов не должны теряться.** Если меняется их структура — повышайте `SCHEMA` в `src/shared/prefs.js` и дописывайте `migrate()` с тестом в `tests/prefs.test.mjs`.
4. **Математические соглашения — как в учебниках:** Φ(x) от −∞ (переключатель на Φ₀), обозначения Серякова, Мэнкью, Пиндайка–Рубинфельда. Сомневаетесь — спросите в Issue, а не угадывайте.
5. Никакой аналитики и аккаунтов.

## Порядок работы

1. `npm test` и `npm run build` должны проходить до и после изменения.
2. **Одна ошибка — один коммит**, сообщение на русском: что было, что стало, как проверено. Пример — `git log`.
3. Исправили ошибку в расчётах — добавьте регрессионный тест рядом (`tests/<тренажёр>.test.mjs` или `tests/math-expr.test.mjs`) с конкретным вводом из сообщения об ошибке.
4. Решатели (`src/math`, `src/apps/*/solvers`) — чистые функции: без DOM, без настроек и без состояния интерфейса. Язык — через `lang()`, обозначения — через провайдер (`notationFrom` в ТВ).
5. Меняете интерфейс — запустите `npm run e2e -- <тренажёр>`. Если поведение меняется **намеренно**, укажите коммит с новым ожидаемым поведением в `tests/e2e/refs.json` и объясните это в сообщении коммита.
6. Меняете ответ решателя намеренно — обновите `tests/golden/<тренажёр>.json` (снимите заново через `tests/golden/capture.mjs` или поправьте только затронутые примеры) и опишите, какие строки изменились и почему.

## Стиль кода

- Форматирование — Prettier по `.prettierrc` (`npx prettier --write "src/**/*.{js,css}"`); коммиты, которые только переформатируют код, записывайте в `.git-blame-ignore-revs`.
- Публичные функции модулей — с JSDoc; в `src/math` и `src/shared` — `// @ts-check`.
- Текст пользователя в HTML — только через `esc()` из `src/shared/esc.js`.
- Тексты интерфейса — в `content/tx.js` на двух языках (ru, en), не в коде.

## Как пользоваться

- **Онлайн** — по ссылке выше, ничего устанавливать не нужно; работает и на телефоне.
- **Офлайн** — откройте нужный тренажёр по ссылке, сохраните страницу (`Ctrl+S` / «Сохранить как») и открывайте файл его двойным щелчком в любом браузере. Без интернета вместо фирменных шрифтов подставятся системные, всё остальное работает.

Настройки, порядок блоков и отметки «прочитано» в справочнике хранятся только в вашем браузере. Никаких аккаунтов и аналитики.

## На чём основано

- «Методы оптимальных решений» — по учебнику *«Избранные лекции по методам оптимизации»* и материалам семинаров (двойственная задача через транспонирование таблицы, балансовые переменные).
- «Теория игр» — по главам 6–9 того же учебника по методам оптимизации (равновесие Нэша, задача торга, кооперативные игры, аукционы), дополнено стандартными темами курса.
- «Теория вероятностей» — по задачнику ВАВТ; обозначения как в нём (Φ(x) — функция распределения N(0; 1) от −∞), есть переключатель на классическую Φ₀(x). Ответы приложения сверены с ответами задачника.
- Номера задач и их краткие условия приведены для удобства подготовки; полные условия — в исходных пособиях.

## Как устроено

Каждое приложение для студента — один самодостаточный HTML-файл: разметка, стили и JavaScript без фреймворков. Внешняя зависимость одна — шрифты Google Fonts.

В репозитории эти файлы собираются командой `npm run build` (Node ≥ 20, без зависимостей) в папку `dist/`, которую GitHub Actions публикует на Pages. Пока тренажёры лежат целиком в `legacy/` и копируются как есть; по мере переноса они переезжают в `src/` (общая оболочка, математическое ядро и решатели отдельно, с тестами `npm test`). Подробный раздел «Разработка» появится по завершении переноса.

Режимы интерфейса описаны явно в начале скрипта (блок «автоматы состояний») и публикуются в атрибутах `<body>`: `data-anim` (`idle` · `playing` · `queued` · `scrub`), `data-gesture`, `data-drawer`, `data-rec`, `data-mode`, `data-shape`. По ним удобно писать стили и автотесты; переключатели отдают состояние через `aria-pressed`. Пока — в «Линейной алгебре».
